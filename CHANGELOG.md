# История изменений

## 1.2.31 — 2026-11-12

- Добавлен TUI-файловый менеджер с управлением стрелками.
- Добавлены переход по каталогам, просмотр текстовых файлов, создание файлов и папок, переименование.
- Добавлено удаление файлов и только пустых папок с подтверждением.
- Добавлено управление файловым менеджером из команды `toolkit files` и главного меню.
- Файловый менеджер работает без root и сторонних Python-библиотек.

- Для переводчика установлен русский язык результата по умолчанию.
- Добавлен ввод текста прямо в интерактивном режиме.

- Добавлены понятные сообщения об ошибках и предупреждение о лимите сервиса перевода.
- README переписан на русском языке и приведён в соответствие с командами проекта.
